## 1. Defect Description
Inverted color channel evaluation in `classify_mask_region()`. When images ingested via Streamlit PIL buffers or OpenCV frame grabbers were passed without colorspace normalization, the blue and red channels inverted (BGR instead of RGB). Warm-toned unmasked human faces with high red channel dominance (`R >> B`) were evaluated as having high blue dominance (`B >> R`), causing the classifier to mistakenly identify bare human faces as wearing a "Surgical Blue / Cyan Mask".

## 2. Steps to Reproduce
1. Ingest an unmasked face image via standard OpenCV BGR channel representation without calling color conversion.
2. Execute `classify_mask_region(face_roi)`.
3. Check condition on line 133: `is_surgical_blue = (b_mean > r_mean + 15) and (b_mean > 85)`.
4. Observe that natural skin red pigment satisfies the inverted `b_mean` check, returning label `Mask` with 0.95 confidence.

## 3. Expected vs. Actual Behavior
- **Expected:** An unmasked bare face must be classified as `No Mask` regardless of ingestion source format.
- **Actual:** Bare faces with warm skin tones were falsely classified as wearing a surgical blue mask (`Mask`).

## 4. Root Cause Analysis
OpenCV default reader (`cv2.imread`) loads arrays in BGR format, whereas Streamlit and PIL use RGB format. `classify_mask_region()` assumed incoming pixel data was strictly RGB, but lacked defensive channel ordering validation. When BGR was passed directly, channel index 0 (Blue) and channel index 2 (Red) inverted the algorithmic logic.

## 5. Developer Resolution (Applied by Software Developer Agent)
- Standardized image loading pipeline in `src/utils.py` with `load_and_validate_image()`, enforcing strict RGB conversion using `cv2.cvtColor(img, cv2.COLOR_BGR2RGB)`.
- Added unit test `test_bgr_to_rgb_and_back` in `tests/test_utils.py` to guarantee deterministic colorspace roundtrips.
- Added strict channel order assertions in `classify_mask_region()` to defensively validate input dimensions and channel integrity.

## 6. QA Retest & Verification Results
